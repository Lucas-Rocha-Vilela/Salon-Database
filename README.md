# Salon-Database
Salon Database developed by Lucas Rocha Vilela, throughout the course Relational Databases Certification from FreeCodeCamp.
In this project, I created a database based on PostgreSQL using Bash Script.

The salon.sh gets the customer information about an appointment, like customer's phone, time of appointment and *name(when the customer isn't registered yet). 
If the customer isn't registered, then salon.sh will register they into salon.sql.
The appointment will be registered into salon.sql by the end of program.
